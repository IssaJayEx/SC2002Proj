README

This folder contains all the UML Class Diagrams showcasing the relations between the different classes we created for this project in stages 1, 2 and 3.

All the diagrams are saved in both SVG file and in PlantUML code for ease of reference if the SVG file is unclear.

Attached is a pdf report which summarises how the UML class diagram changed from Stage 1 to Stage 3, how the relationships between classes changed, application of the SOLID design principles in our project and describes the final Stage 3 class diagram.
