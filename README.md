SC2002 – Restaurant Rush

1. Project Overview

Restaurant Rush is a Java-based restaurant management simulation game developed as part of the SC2002 Object-Oriented Design & Programming group project.

Players manage a restaurant by making decisions, managing resources, and completing tasks throughout the game.

The project was developed incrementally across three stages, demonstrating the application of object-oriented programming principles and the ability to extend an existing software design to accommodate new requirements.

3. How to Run the Game

**Requirements**
- Java Development Kit (JDK): Version 21 or higher
- Eclipse IDE or another Java-compatible IDE

**Instructions**

    1. Open Terminal and enter:
        - cd ~ 
        - cd ~/Desktop
        - git clone https://github.com/IssaJayEx/SC2002Proj.git
        - cd SC2002Proj
        - git checkout stage-1 (or stage-2/stage-3 as according)

    2. Open Eclipse IDE

    3. File -> New -> Java Project
        - Name it "SC2002Proj" (Note: Do not have any SC2002Proj files)
        - Untick "Use Default Location"
    
    4. Find SC2002Proj file in Desktop and Finish

    5. Open src -> restaurantrush.model

    6. right click CLI.java -> run as -> Java Application
