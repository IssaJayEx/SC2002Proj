SC2002 – Restaurant Rush

1. Project Overview

Restaurant Rush is a Java-based restaurant management simulation game developed as part of the SC2002 Object-Oriented Design & Programming group project.

Players manage a restaurant by making decisions, managing resources, and completing tasks throughout the game.

The project was developed incrementally across three stages, demonstrating the application of object-oriented programming principles and the ability to extend an existing software design to accommodate new requirements.
